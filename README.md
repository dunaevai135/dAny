# dAny6-sim

Генератор кубиков dN произвольной формы (`dAny6.py`) и Монте-Карло проверка их честности в MuJoCo (`dice-sim`).

## STL

```sh
uv run python dAny6.py --sides 14 --seed 777                   # оба варианта
uv run python dAny6.py --sides 14 --variants equal             # только выровненный
```

- `thomson` — нормали граней из релаксации Томсона;
- `equal` — те же нормали, подогнанные так, чтобы площади сферических ячеек Вороного были равны
  (`equalize_voronoi_areas` в `src/dany6_sim/geometry.py`).

Файлы: `d{N}_s{seed}_{variant}.stl`.

## Развёртка по CUT_FACTOR (гравированные STL)

```sh
DICE_FONT=/path/to/TSCu_Comic.ttf scripts/run_cut_sweep.sh
THROWS_PER_CUT=40000 WORKERS=32 RENDERS_PER_CUT=3 scripts/run_cut_sweep.sh
```

Скрипт генерирует STL для каждого `CUT_FACTOR` (`stl_cut/`, готовые пропускаются), гоняет симуляцию
с равной квотой бросков на каждый, строит отчёт `flat_sweep_bottom.png` и пишет видео в `<OUT>/render`.
Повторный запуск дописывает новые броски в ту же папку. Шрифт обязателен: без него `dAny6.py`
возьмёт Arial, и цифры (а значит, и выпуклая оболочка) будут другими.
Переменные: `SIDES`, `SEED`, `VARIANT`, `CUTS`, `THROWS_PER_CUT`, `MASS`, `WORKERS`, `STL_DIR`, `OUT`,
`RENDERS_PER_CUT`, `MUJOCO_GL` (`egl` по умолчанию, без GPU — `osmesa`).

## Симуляция

```sh
uv run dice-sim run --sides 14 --throws 120000          # → runs/d14_s777/throws_<seed>.npz
uv run dice-sim report runs/d14_s777                     # таблица + графики в ту же папку
uv run dice-sim report runs/a runs/b --variants thomson,thomson-stl --out runs/cmp   # сравнение прогонов
uv run dice-sim report runs/d14_s777 --readout top       # читать верхнюю грань вместо нижней
MUJOCO_GL=egl uv run dice-sim render --count 2           # пара контрольных видео
uv run dice-sim calibrate                                # таблица dampratio → e
```

Повторные `run` в ту же папку дописывают новые файлы, `report` объединяет все.

### Что варьируется

| опция | смысл | по умолчанию |
|---|---|---|
| `--variants` | формы | `thomson,equal` |
| `--mass` | распределение массы: `solid`, `shell:T[:INFILL]` (стенка T мм, доля заполнения внутри) | `solid,shell:1.2` |
| `--mu` | трение скольжения | `0.05:1.0` |
| `--e` | коэффициент отскока при ударе гранью | `0.1:0.7` |
| `--roll` | трение качения, м (верчения ×5) | `0.0002` |
| `--height`, `--speed`, `--spin` | начальные условия броска | |
| `--flat` | `CUT_FACTOR` через запятую — каждое значение отдельная конфигурация | `1 − 1.76/N` |
| `--stl-dir .` | брать реальные STL с гравировкой (масса и ЦМ с учётом цифр) вместо гладкой формы | |

`a:b` — равномерная выборка на отрезке, `a,b,c` — случайный выбор из уровней (сетка).
Каждая конфигурация = вариант × модель массы; все крутятся в одном мире.

### Модель

- Тело — выпуклая оболочка «шар ∩ полупространства», та же форма, что режет `dAny6.py`.
- Инерция считается по мешу (знаковые тетраэдры), оболочка = тело − масштабированное ядро.
- В одном мире MuJoCo `--slots` независимых кубиков (друг с другом не сталкиваются),
  как только кубик успокоился — результат пишется и слот сразу получает новый бросок со своими μ, e.
  Процессов — по числу ядер.
- MuJoCo задаёт контакт пружиной-демпфером, поэтому e переводится в dampratio по калибровочной
  таблице (бросок гранью вниз), отдельно для каждой конфигурации. Шаг 0.25 мс: при более крупном
  слабодемпфированный контакт неустойчив. Достижимый e ≲ 0.75.
- Ниже 0.15 м/с контакт критически демпфирован (аналог restitution threshold в Bullet/PhysX) —
  иначе кубик бесконечно раскачивается на грани.
- Трение качения обязательно: без него кубик катается по круговой кромке грани как диск Эйлера.
- Покой — скорость < 5 мм/с и < 0.3 рад/с в течение 0.15 с. Если при этом грань не легла
  (наклон > 2°), кубик замер на сферическом остатке угла: исход `-1` («на угол»), в статистику граней не идёт.

### Метрики отчёта

- **RMS** — среднеквадратичное отклонение p_i·N от 1 с вычтенным шумом выборки:
  √max(0, (χ² − (N−1))/n). Сравнимо между бинами с разным числом бросков.
- **β** — коэффициент регрессии (p_i·N − 1) на (a_i − 1), где a_i — относительная площадь Вороного:
  какая доля квазистатического перекоса дошла до динамики. 1 — чистая квазистатика.
- ДИ — basic-бутстрэп по мультиномиальной перевыборке.
